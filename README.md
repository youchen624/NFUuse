## 📖 學習歷程

### 🟢 大一上學期（2024/09 - 2025/01）

**重點課程**:
- **計算機程式設計** & **計算機程式設計實習**
  - 學習 C/C++ 基礎語法
  - 陣列、函式、指標應用
  - 87 個程式作業

**學習主題**:
```
✓ 基礎語法與變數
✓ 流程控制（if, switch, for, while）
✓ 陣列與字串處理
✓ 函式與參數傳遞
✓ 指標基礎
✓ 結構與資料處理
✓ CPE 程式檢定
```

**關鍵里程碑**:
- 10/09: 開始程式設計實習
- 11/13: 完成陣列主題（4個專案）
- 11/28: 開始 CPE 練習
- 12/12: CPE 小考

---

### 🟡 大一下學期（2025/02 - 2025/06）

**重點課程**:
- **程式設計** - 進階 C/C++ 程式設計
- **數位系統** - 硬體邏輯設計入門

**學習主題**:
```
✓ 進階程式設計技巧
✓ 數位邏輯設計
✓ Verilog/VHDL 硬體描述語言
✓ Quartus 開發環境
✓ 計算機網路概論
```

**技術轉換**:
- 從純軟體開發延伸至硬體設計
- 開始使用 Quartus 進行數位電路設計
- 完成 62 個 Verilog/VHDL 專案

---

### 🔵 大二上學期（2025/09 - 2026/01）

**重點課程**:
- **Java程式設計** - 物件導向程式設計
- **資料結構** - 演算法與資料結構

**學習主題**:
```
✓ Java 語言基礎
✓ 物件導向程式設計（OOP）
✓ 類別與物件
✓ 繼承與多型
✓ 介面與抽象類別
✓ 資料結構實作
✓ 演算法分析
```

**學習節奏**:
- 09/19 - 12/26: 持續 13 週的 Java 課程
- 完成 34 個 Java 程式作業
- 持續參與 CPE 練習（6個檔案）
